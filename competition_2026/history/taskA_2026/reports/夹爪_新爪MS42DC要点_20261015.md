## 1. 接口（手册表 1-1）
| 接口 | 说明 | 规格 |
| --- | --- | --- |
| 接口一 | 电源输入 + 通信（默认 CAN） | XH2.54 4Pin |
| 接口二 | 电源输入/输出 + 通信（默认 CAN），可级联 | XH2.54 4Pin |
| 接口三 | NPN 外部控制 | XH1.25 4Pin |
| USB | 下载 / 串口 / 上位机 | TYPE-C USB2.0 |
| 拨码开关 | 1 = 程序下载；2 = 通信协议/控制模式 | 2 位 |

- 接口一/二线序：1 电源负极、2 CAN-H / UART_RX、3 CAN-L / UART_TX、4 电源正极。
- 级联：A 的接口二 → B 的接口一，靠设备地址区分（TTL 用帧内地址，CAN 用 ID）。
- 接口三（NPN，低电平有效）：4 = GND；**1→GND = 张开**；**3→GND = 闭合**；2 空。
  注意 VC 为电源电压（12/24V），不能直接用 MCU IO 拉低，要用 MOS/三极管/光耦。
- USB 串口固定 115200；走 USB 时拨码开关 2 要打到 ON。

## 2. 性能
- 输入 10–25V，最大工作电流 1.2A（法兰 M8 的 24V 可给 2A，余量足够）。
- 转速 0.95–420 RPM（0.1–43.96 rad/s）。
- **只支持位置模式**（2026-02-08 起速度模式取消）。
- 堵转保护：夹到最紧即停，因此实际到达角度会有少量偏差。
- 不支持热插拔（先接线后上电）；有过压/反接保护。

## 3. 串口协议（USB 与 TTL 电平串口一致，11 字节）
```
7B | ID | 02 | dir | 细分 | POS_H POS_L | SPD_H SPD_L | BCC | 7D
```
- ID 默认 0x01；dir：0 = 逆时针 = 张开，1 = 顺时针 = 闭合；
- 细分：2/4/8/16/32（建议 16 或 32）；POS、SPD 均为「实际值 ×10」；
- BCC = 前 9 字节异或和；帧尾 0x7D。
- 闭合示例：`7b 01 02 01 20 49 20 00 c8 f8 7d`（1872° @ 20 rad/s，5.2 圈）
- 张开示例：`7b 01 02 00 20 49 20 00 c8 f9 7d`
- 状态查询：`7b 01 00 00 00 00 00 00 00 7a 7d` → 返回 9 字节：
  地址 | 到位标志(1=到位) | 速度H 速度L | 角度32位×10 | RCC。
- 长时间未使用自动失能、反馈频率、电流、地址、波特率均可用上位机改并掉电保存。

## 4. CAN
- 默认 ID = 1，波特率 1 Mbit/s；8 字节：`02 | dir | 细分 | POS_H | POS_L | SPD_H | SPD_L`（无帧头/帧尾/BCC）。
- 反馈接收 ID 固定 0x0A。

## 5. ROS 例程（已解压确认）
- 包：`step_motor`（`motor_node`）+ `serial_ros2`（ROS1/ROS2 两份源码在资料里）。
- 话题：`/motor_control`（`step_motor/msg/Motor`: id, speed, dir, mode, angle, state, sub_divide）；`/motor_state` 反馈。
- 串口默认 `/dev/motor_serial`、115200（用 `ch9102_udev.sh` 建 udev 别名）。
- 张开：`{id:1, speed:200, dir:0, mode:2, angle:30000, sub_divide:32}`
- 闭合：`{id:1, speed:200, dir:1, mode:2, angle:30000, sub_divide:32}`
- mode：2 = 相对角度，4 = 绝对角度；angle 需放大 10 倍。
- 固件（`3.程序固件/源码3.0`）按闭合圈数分档：4.5/4.7/4.9/5.1/5.3/5.5/5.8/6.1/7.0/7.5/8.5/9.5 圈；
  V2.0 时期曾按 两指/三指/四指 分 hex（两指 = `机械爪-两指-20240702-V2.0.hex`）。
- 版本识别：上位机代码版本 ≥ 2.2.0 → V3.0；< 2.2.0 → V2.0。
