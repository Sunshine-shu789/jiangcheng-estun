1.2.1. 堵转保护

   在发生堵转后，电机会停止转动。机械爪在夹取物品时会判断是否堵转，也
就是在夹取大物品时，夹子收缩到最紧时，就会停止转动。

1.2.2. 输入反接保护

   主控的输入电源处增加了电路设计，避免电源输入正极与负极接反时烧毁板
子，但用户应尽量避免将电源反接。

1.2.3. 多机级联使用

   多个 MS42DC 电机级联使用时，可以通过接口一和接口二衔接使用。假设
有三个电机 ABC。A 电机的接口二接 B 电机的接口一，B 电机的接口二接 C 电
机的接口一，即可实现多个电机的供电与通信上的硬件连接。更多关于电机级联
使用的内容，请参考章节“5.多个电机级联使用”。

1.2.4. 精度参数说明

   V2.0 版本电机使用的编码器芯片为 SC60224，是一个 500 线的编码器，经
过单片机编码器模式 4 倍频后，变为了 2000 线，所以精度为 360/2000=0.18°，
但是通过步进电机的细分步数的调节控制后，可以达到 0.1 度的实际精度。
   V3.0 版本电机使用的编码器芯片为 MT6816，是一个 14 位分辨率的磁编码
器芯片，所以理论上可以达到的精度为 360/16384=0.0219°，但是实际精度还受
到其余的控制条件影响，所以实际控制精度为 0.05°。
  区分 V2.0 和 V3.0 可以通过上位机代码版本号进行区别，2.2.0 以上为 V3.0
版本电机，2.2.0 以下（如 V2.1.6）为 V2.0 版本电机。

3. 控制模式与通讯协议
    本章内容主要介绍 MS42DC 电机的所有控制模式及其对应的控制协议，为确
保正常使用，以下会先介绍部分注意事项。
    TTL 电平串口控制模式和 USB 串口控制的通信方式和通信协议是一致的，所
以无论是接口 1 上的 TTL 电平串口控制或者是 TYPE-C 的串口一控制皆可参考下
面的内容.接口 1 的 TTL 电平串口波特率可以通过上位机进行设置（具体操作参
考章节“4.上位机软件使用”），USB 串口的波特率固定为 115200 不可修改。
需要注意的是：如果是通过 USB 串口接口来发送数据，要将拨码开关 2 打到 ON,
否则接收不了数据.
   位置控制模式中可以调节它到达目标的速度，（位置控制下的快到达目标位
    置会有一个加减速过程，所以在控制角度小时会速度达不到目标速度）位置
    控制模式下单次的控制电机转动的最大角度为 6553.5 度（两个字节最大为
    65535，放大十倍发送）。
（速度模式不可用，机械爪只适用于位置控制模式）

误检测和数据校验的功能，所以此处就不添加 BCC 校验位。

3.3. TTL 电平串口控制

  TTL 电平串口接口和 CAN 是公用引脚。默认为 CAN 通信控制，通过上位机可
以进行切换，选择对应的通信模式，然后点击保存设备参数即可。




                  图 3-1 上位机修改通信接口图示
   TTL 电平串口控制和 USB 串口控制的通信协议是一致的，只不过 TTL 电平串
口控制可以支持多个电机级联使用，在多个电机级联使用时，只需要改变每个电
机的设备地址就可以完成不同的功能。使用 TTL 电平串口时，注意需要共地。协
议参考上方的 USB 电平串口控制。

3.5.   NPN 接口控制

   在该模式下，需要用到接口 3 来进行一个外部控制，4 号引脚为 GND，当接
口 3 的其余三个引脚接到 GND 时，会有不同的效果，1 号引脚接到 GND 时，机械
爪会张开，3 号引脚接到 GND 时，机械爪会闭合，2 号引脚无控制效果。




                  图 3-3 NPN 接口电路图

   NPN 接口为低电平有效，但 VC 为电源电压，接入 12V 或 24V，所以不能
直接与单片机引脚连接，否则容易烧坏 IO，如果想要实现单片机控制，则需要
使用 MOS 管作为开关。
   可以将机械爪和控制主板共地，然后将控制主板的 IO 口连接到接口 3，这
样即可实现控制主板控制机械爪的闭合，如连接 3 号引脚的 IO 口输出低电平即
可实现机械爪闭合，连接 1 号引脚的 IO 口输出低电平即可实现机械爪张开，张
开到设定的位置后就会停止（默认设定几乎到达极限位置）。
   修改位置控制控制模式下的速度就是修改此模式的速度（重新上电后会恢复

3.6.         CAN、TTL 串口对外发送数据

       电机的实时转速和实时角度数据(放大十倍发送)可以通过 CAN 或者 TTL 串
口、USB 串口发送，CAN 接收的 ID 固定为 0x0A。电机数据的反馈有两种模式，
可以通过上位机进行设置为固定频率(20Hz)发送或者请求发送，默认为请求发送，
数据请求发送协议为：串口：7b 01 00 00 00 00 00 00 00 7a 7d；CAN 为：01 00 00
00 00 00 00。在机械爪控制中，我们采用的是软件检测堵转然后实现的堵转保护，
以便机械爪在抓取到物体达到最紧后停止机械爪继续收紧，所以会导致一个问题，
在位置控制时转动到的角度会存在少许偏差量。

4.2.   功能介绍




                 图 4-3 上位机软件界面图示

   在上位机控制模式中，点击电机归零（机械爪无效），那么电机就会转动到
    一圈 360 度中的 0 度位置；点击角度校准按键，即可设定电机目前所在的位
    置为 0 度位置，那么下次的电机归零既是转动到目前角度校准的位置。
   长时间未使用失能设置是指在位置模式时超过设定的时间没有给电机传输
    新的数据内容时电机会失能，如在让电机转动了 360 度，接着十分钟内没有
    让电机再次转动，则电机会失能，从而减少待机发热的状况，只需要传输新
    的数据即可重新使能电机。（在失能状态下电机失去力矩）
   数据反馈设置可以设定电机的实时速度和实时位置是以固定频率反馈还是
    请求反馈。
   在电机目标转速 rad/s 空格输入转速，例如图中输入了 10rad/s，选择电机正
    转按钮，然后点击开始按键，则电机会以 10rad/s 的速度顺时针转动，选择
    电机反转按钮再点击开始，则电机会以 10rad/s 的速度逆时针转动，点击停
    止按键，则电机会停止转动，电机停转该按键是可以控制所有状态下的电机
    停转。例如让电机转动 3600 度，在途中点击了电机停转按钮，也会停止转
    动。
   在电机位置控制模式中，选择正转，输入目标转速，在电机目标位置空格输
    入目标位置后，点击开始按键，则电机会以目标转速正转转动到设定的目标
    位置，电机目标位置是以角度为单位，例如上图的 360（限制了最大值为 6553），
    则是电机转动 360 度，也就是 1 圈。
   在常规模式下运行电流值 mA 方框输入电流大小，点击发送按键后电机运行
    时电流大小则会如输入的大小并且掉电保存，如上图输入 200mA，那么此时
    电机的力矩会很小，用手就可以掐停，重新上电后电机也会以 200mA 电流
    运行。最大电流值为 1200mA。点击获取按键后则会获取到目前电机的电流
    大小。（为保证机械爪正常使用，内部程序已写定电流最小为 700mA）
   点击获取设备参数按钮可以得到该板子的参数，如细分值、地址设置、通信
    接口设置、CAN 波特率、串口波特率、长时间是否失能设置、代码版本号。
   在参数设置区域还可以对这些参数进行修改，修改完后，点击保存设备参数
    即可进行保存，断电后也是设置后的参数。
   点击恢复出厂设备参数按键后，驱控板即可恢复出厂的设置，细分值为 32，
    设备地址为 1，通信接口设置为 CAN、CAN 波特率为 1000000，串口波特率
    为 115200，长时间是否失能为否。
5. 多个电机级联使用
  对应多个电机级联使用，只针对接口 1 和接口 2，上文已经提及，接口 1 和
接口 2 都可以是输入或者输出的。这不只是电源输入输出而已，还有 CAN 信号
或 TTL 电平串口信号输入输出，以至于达到一个设备可以控制多个电机的目的。
  对于级联使用，我们需要注意的是，每个电机的控制可能会不一样，如一个
电机转动 90°，一个电机转动 180°，而 CAN 通讯或 TTL 电平串口通讯在级联
情况下都是共用一个通讯线路，这就需要区分电机接收的数据了，我们通过电机
的设备地址进行区分。而电机的设备地址我们可以通过上位机方面来进行设备地
址的修改。如下图所示，将地址设置选择为 3，然后电机保存设备参数按钮即可
将 MS42DC 电机的设备地址改为 3 了。




                 图 5-1 设备地址修改图示

  电机的设备地址修改完成了，下面就是要注意 CAN 通讯和 TTL 电平串口通
讯控制下的地址了。机械爪默认 CAN 通讯。
CAN 通讯控制：
    CAN 通讯中的地址并不是在发送的数据中修改的，CAN 通信本身就需要发
送给相应的 ID 号，所以 CAN 通讯只需要修改相应的 ID 号即可，如 1 号电机的
设备地址为 0x01，那么 CAN 通讯时的 ID 号就是 0x01。
如下面所示：让 1 号电机转动 90 度、2 号电机转动 360 度、3 号电机转动 180
度。
* 函数名称：CAN1_Send_Num(u32 id,u8* msg)
* 入口参数：id ID 号，msg 被输送数组的名称
* 函数输出： 1，发送失败； 0，发送成功
* 函数功能：给给定的 id 发送一个数组的命令
u8 CAN1_Send_Num(u32 id,u8* msg)
{
    u8 mbox;
    u16 i=0;
     mbox=CAN1_Tx_Msg(id,0,0,8,msg);
    while((CAN1_Tx_Staus(mbox)!=0X07)&&(i<0XFFF))i++;//等待发送结束
    if(i>=0XFFF)return 1;                     //发送失败?
    return 0;
}
u8 CAN_SENT1[7]={0x02 0x01 0x20 0x03 0x84 0x00 0x64}
u8 CAN_SENT2[7]={0x02 0x01 0x20 0x0e 0x10 0x00 0x64}
u8 CAN_SENT3[7]={0x02 0x01 0x20 0x07 0x08 0x00 0x64}
/********************************************************************
函数功能：can 数据发送
入口参数：无
返回 值：无
*******************************************************************/
void can_send_task(void)
{
         CAN1_Send_Num(0X01,CAN_SENT1);           //can 发送数据
         CAN1_Send_Num(0X02,CAN_SENT2);           //can 发送数据
         CAN1_Send_Num(0x03,CAN_SENT3);
}
TTL 电平串口控制：
    TTL 电平串口控制的设备地址就是在发送的数据中，所以想要相应的电机转
动，那就需要发送相应的设备地址，在 3.1 中就提到设备地址是第二个字节，那
如果想要让 1 号电机转动 90 度、2 号电机转动 360 度、3 号电机转动 180 度，则
发送一下的数据。
*   函数名称：CAN1_Send_Num(u32 id,u8* msg)
*   入口参数：id ID 号，msg 被输送数组的名称
* 函数输出： 1，发送失败； 0，发送成功
* 函数功能：给给定的 id 发送一个数组的命令
void usart1_send(u8 data)
{
    USART1->DR = data;
    while((USART1->SR&0x40)==0);
}
u8 usart_sent1[11]={0x7b 0x01 0x02 0x01 0x20 0x03 0x84 0x00 0x64 0xBA 0x7d}
u8 usart_sent2[11]={0x7b 0x02 0x02 0x01 0x20 0x0e 0x10 0x00 0x64 0x20 0x7d}
u8 usart_sent3[11]={0x7b 0x03 0x02 0x01 0x20 0x07 0x08 0x00 0x64 0x30 0x7d}

/********************************************************************
函数功能：串口 1 的发送函数
入口参数：无
返回 值：无
********************************************************************/
void usart1_send_task(void)
{
    int num=11;
    int i;
    for(i=0; i<num; i++)
    {
        usart1_send(usart_sent1[i]);
        usart1_send(usart_sent2[i]);
        usart1_send(usart_sent3[i]);
    }
}
