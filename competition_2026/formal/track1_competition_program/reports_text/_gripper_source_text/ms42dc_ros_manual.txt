2. ROS1

1   串口功能包安装

    ROS1 可以通过二进制安装串口驱动包，具体指令为：
     sudo apt install ros-melodic-serial    (ubuntu18)
     sudo apt install ros-noetic-serial     (ubuntu20)


2   源码编译

    将 ROS1 源码复制到系统里，在源码根目录打开终端通过

catkin_make 编译。

3   键盘控制

    在 ROS1 中可以通过键盘的方式控制电机速度模式的速度大小，

方向，细分值，查询电机状态等信息。

    首先运行串口底层节点：
             roslaunch   step_motor step_motor.launch

    键盘速度模式控制节点：
             rosrun   step_motor   key_control.py

    键值对应:
        Q             增大速度分辨率                    D       电机换向


         A            减少速度分辨率                    R       id 递增

         W       增大电机运动速度                        V       id 递减

         X       减少电机运动速度                        F       查询电机状态


         S             电机停止                      Z       更改电机细分值

4    位置控制

     位置模式通过话题发布的形式控制,可参考图 2-2。

     首先运行串口底层节点：
               roslaunch   step_motor step_motor.launch

     话题发布：电机 id 1,相对模式下旋转 90 度，细分 8，速度 100。
               rostopic pub /motor_control step_motor/Motor "{id: 1, speed: 100,
           dir: 0, mode: 2, angle: 900, state: 0, sub_divide: 8}"


                  id          电机唯一 ID
               speed          到达目标角度的速度
               mode           运动模式，2 为相对角度模式，4 为绝对角度模式
               angle          运动角度，需要放大十倍发送
               state          电机状态查询，控制电机时为 0
            sub_divide        电机细分值：2/4/8/16/32

     注：如需用来控制夹爪的张开闭合，需要增大旋转的角度，可参

考下面的指令：

     张开：rostopic pub /motor_control step_motor/Motor "{id: 1, speed: 200, dir:
0, mode: 2, angle: 30000, state: 0, sub_divide: 32}"


     闭合：rostopic pub /motor_control step_motor/Motor "{id: 1, speed: 200, dir:
1, mode: 2, angle: 30000, state: 0, sub_divide: 32}"

2   键盘控制

    在 ROS2 中可以通过键盘的方式控制电机速度模式的速度大小，

方向，细分值，查询电机状态等信息，位置模式则通过话题发布的形

    首先运行串口底层节点：
           ros2 run   step_motor   motor_node

    键盘速度模式控制节点：
           ros2 run   wheeltec_robot_keyboard   wheeltec_keyboard


       Q         增大速度分辨率                    D          电机换向


       A         减少速度分辨率                    R           id 递增

       W        增大电机运动速度                    V           id 递减

       X        减少电机运动速度                    F          查询电机状态


       S              电机停止                  Z          更改电机细分值


    电机状态查询：
           ros2 topic echo /motor_state         (键盘控制节点按 F)

3    位置控制

     位置模式通过话题发布的形式控制，首先运行串口底层节点：
                ros2 run   step_motor   motor_node

     话题发布：电机 id 1，绝对模式下旋转 90 度，细分 8，速度 100
                ros2 topic pub --once /motor_control step_motor/msg/Motor "{id:

                  id          电机唯一 ID
               speed          到达目标角度的速度
               mode           运动模式，2 为相对角度模式，4 为绝对角度模式
               angle          运动角度，需要放大十倍发送
               state          电机状态查询，控制电机时为 0
            sub_divide        电机细分值：2/4/8/16/32

     注：如需用来控制夹爪的张开闭合，需要增大旋转的角度，可参

考下面的指令：

张开：ros2 topic pub --once /motor_control step_motor/msg/Motor "{id: 1,speed:
200,dir: 0,mode: 2,angle: 30000,state: 0,sub_divide: 32}"


闭合：ros2 topic pub --once /motor_control step_motor/msg/Motor "{id: 1,speed:
200,dir: 1,mode: 2,angle: 30000,state: 0,sub_divide: 32}"
