1. 正式启动器明确处于安全试运行模式，因此即使规划成功也不会发送实体动作。
2. 早期视觉目标把目标检测中心直接当成夹爪尖，而教学成功样本显示实际夹爪尖
   相对香蕉中心在物体水平主轴/次轴坐标中有约 `23.59 mm` 的偏移。直接使用
   检测中心会生成错误的目标位姿。
3. 早期配置的 yaw 与教学成功姿态相差约 `66.74 deg`。
4. 修正几何后，教学 RPY 的端点第一次仍因 IK 残差超限被拒绝；加入围绕教学
   RPY 的小角度 pitch 分支后，`-5 deg` 分支通过完整路线。所有失败都发生在
   任何运动或夹爪动作之前，属于 fail-closed 安全行为。

本次没有切换 live 配置。进行实体抓取前，必须由操作员明确确认现场安全检查
通过，并至少满足：

1. 急停按钮可由操作员立即按下，工作区内无人。
2. 控制器保持 `AutoReady`、无故障，当前香蕉位置不再变化。

   `mock` 的成功结果当成夹持成功。
5. 首次实体动作应限制为单个点位、单次抓取，并持续观察急停和机械臂状态。
