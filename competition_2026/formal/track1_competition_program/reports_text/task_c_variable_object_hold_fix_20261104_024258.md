# Task C/D 变尺寸物体夹持判定修复

日期：2026-11-04

## 结论

上一轮实机日志中的物品已经被夹住，失败发生在 `verify_hold`：固定终角门限
`hold_min_angle_deg=1978.0` 把 `1978.0 deg` 的真实夹持误判为空夹，随后安全恢复
立即张爪并退回预抓取位。

比赛物品尺寸不一致，MS42DC 状态反馈中的角度是电机/编码器读数，不是独立的
夹爪开口或负载测量。因此不存在一个适用于所有物品的固定“空夹终角”。

## 修改

1. C/D 宽度感知模式不再使用固定空夹终角。
2. `close_for_width` 继续按当前物体的测得短边宽度、CAD 夹爪型面和行程容差验证
   闭合行程；不足时仍然 fail-closed。
3. `MS42DCHoldVerifier` 在宽度感知模式下只要求控制器连续报告稳定到位，不再比较
   `hold_min_angle_deg`。
4. C/D 真机配置校验要求：
   - `require_close_travel_evidence: true`
   - `hold_min_angle_deg: 0.0`
5. 四份正式 C/D 配置均已更新。

## 回归验证

- 固定终角 `1978.0 / 1978.4 / 1978.8 deg` 在宽度感知模式下均接受。
- 管线级测试确认终角 `1978.0 deg` 时仍执行
  `grasp -> lift -> transfer -> release -> retreat`，不在转运前张爪。
- 相关测试：`168 passed`。
- 配置/管线扩展测试：`145 passed, 1 skipped`。
- 四份正式配置均可加载并通过 `validate()`。

本轮未启动实体机械臂或实体夹爪。

## 剩余限制

当前 MS42DC 协议没有电流、转矩或独立夹持检测。宽度感知 `close_for_width` 能证明
闭合行程覆盖当前物体宽度，但不能在不夹到物体时绝对证明两指之间存在物体。若后续要
严格识别空抓，应增加电机电流/转矩堵转证据，或增加“短距离提升后视觉复核”流程，
而不是恢复固定终角门限。
