# 赛道一已有照片多物品 bbox 复核说明

## 1. 这套工具做什么

这套工具只处理已经采集完成的赛道一 RGB-D 照片，用来给照片画 YOLO 目标检测框：

- 不打开相机。
- 不连接机械臂或夹爪。
- 不启动 ROS。
- 不修改原始照片。
- 不修改原来的照片采集网页和两个旧识别入口。
- 当前只做“训练数据准备”，不会自动开始训练模型。

正式程序位置：

```text
/media/sunshine/新加卷/埃斯顿比赛_2026/赛道一比赛程序
```

原始照片仍保留在原位置，不移动、不复制到主目录。

## 2. 为什么不是给 1084 张照片全部画框

后类照片来自 348 个 burst（`split_unit`）。同一 burst 内通常是同一摆放场景的 2-9 张近重复照片。

复核工具从每个 burst 中选择 1 张清晰度较高的代表帧：

- 代表帧总数：348 张。
- train：268 张。
- val：80 张。
- 原 burst 的 train/val 归属保持不变，不会让同一 burst 同时进入 train 和 val。
- 只给代表帧画框，避免对同一摆放场景重复标注。

如果某个 burst 的其他帧包含代表帧没有的清晰物体，必须先记录问题，后续再单独补帧；不要默认所有 burst 都完全相同。

## 3. 最重要的多物品同框规则

采集照片时选择的类别、文件名里的类别，只是“这一组照片主要采集了哪个物品”的提示。

它不是本图唯一类别，也不是自动标签。

一张图片必须按以下规则处理：

1. 图中所有清晰可辨、能够确认属于 40 类清单的物品，都要分别画框。
2. 一张图可以有多个不同类别。
3. 同一类有多个实例时，每个实例分别画一个框。
4. 小物品要先用页面缩放功能放大，再画框；不要因为小就当作空图。
5. 物体被部分遮挡但类别仍可确认时，框住可见部分。
6. 无法确认类别、或不属于清单的杂物，不要猜标签。
7. 不要给桌面、箱壁、11L 收纳箱本身、背景或整张图画“伪框”。
8. 画面里确实没有任何可辨认的已知物品时，使用“本图无已知物品（空标签）”。

空标签的行为：

- 导出一个 0 字节的 `.txt`。
- 不创建“空背景”YOLO 类别。
- 不会出现 `box_11L_empty` 之类的场景类别。

## 4. 17、26 类怎么处理

本轮没有实物、没有采集照片的类别是：

- 17：蛋形毛绒玩具。
- 26：塑料草莓。

处理方式：

- 不采集、不补拍。
- 页面标注类别下拉框不提供 17、26。
- 如果图中出现无法确认的物品，不要拿 17、26 或其他相近类别代替。
- 导出时仍然保留官方 1-40 的类别槽位，17、26 是空槽。
- 最终模型预期可识别 38 类，但 YOLO 的 `nc` 仍为 40。

## 6. 每张图的标注步骤

### 第一步：查看素材提示

右侧“当前图片”会显示：

- train 或 val。
- 代表帧编号。
- 同组帧数。
- 本组照片采集时的类别提示。

注意：这里只是提示，必须检查整张图片。

### 第二步：画第一个物品

1. 在“新框默认类别”中选择真实类别。
2. 确认处于“框选 [F]”模式。
3. 在图片上拖动画框。
4. 检查框是否贴着物体边界。

### 第三步：继续画同图的其他物品

1. 重新选择下一个物品的真实类别。
2. 继续拖动画框。
3. 同类多个实例要逐个画框。
4. 框列表中可以修改类别和坐标，也可以删除单个框。

页面支持：

- 放大、缩小和“适应”按钮。
- `Ctrl + 滚轮`缩放。
- `F`：框选模式。
- `V`：移动/调整模式。
- 拖动框可移动，拖动右下角可调整大小。
- `Delete` 删除当前选中的框。
- `A` / `D` 上一张 / 下一张。

### 第四步：保存

- 有物品：点击“保存并下一张 [Ctrl+S]”。
- 只保存但留在本图：点击“仅保存”。
- 整图没有已知物品：点击“本图无已知物品（空标签）”，确认后保存。
- 暂时无法判断：可以“跳过本图”，但跳过会使审计保持未完成。

“保存并下一张”会写入正式复核 JSON 和带框预览图。

## 7. 候选框怎么用

页面可能显示两类虚线候选：

- 蓝色：深度平面分割候选。
- 紫色：YOLO-World 候选。

它们只是辅助提示：

- 都可能漏检。
- 都可能误检。
- 深度候选容易把箱壁、背景、边缘算进去。
- YOLO-World 对后 28 类准确率有限。

不能直接全选候选当标签。点击“加框”后仍必须：

1. 确认类别是否正确。
2. 调整边界。
3. 补齐候选没有发现的其他类别和实例。
4. 删除误加入的框。

## 8. 如何判断可以结束人工复核

必须满足：

- 进度中“未复核”为 0。
- “跳过”为 0。
- 每张多物品照片都已检查整图，而不是只标文件名对应物品。
- 小物品已放大检查。
- 17、26 没有被错误标注。
- 空标签只用于确实没有已知物品的图片。

网页筛选建议：

1. 先用“未复核”逐张处理。
2. 再用“全部”抽查已保存项。
3. 最后检查“空背景”和“跳过”列表。
4. 确认没有问题时再导出。

## 10. 什么时候才能说“可以开始训练”

当前这套导出只包含后类照片的多物品 bbox，不能单独作为最终训练集。

导出审计中应看到：

```text
complete_review: true
postclasses_merge_ready: true
training_ready: false
```

`training_ready` 保持 `false` 是正确的，因为还缺少：

- 前 1-10 类 bbox 数据合并。
- 最终 40 类槽位检查和逐类 train/val 校验。
- 同一 burst 不跨 train/val 的最终检查。
- 最终合并数据审计报告。

只有以下条件全部满足，才会另行通知“可以开始训练模型”：

1. 后类人工 bbox 复核全部完成，无跳过。
2. `postclasses_merge_ready: true`。
3. 前 10 类 bbox 数据存在，且与后类合并时没有覆盖或丢类。
4. 合并后 `nc=40`，17、26 保留空槽。
5. 合并审计确认每个实际可识别类别都有 train 和 val 样本。
6. 合并后不存在整图伪框、类别越界、同一 burst 跨划分等问题。
