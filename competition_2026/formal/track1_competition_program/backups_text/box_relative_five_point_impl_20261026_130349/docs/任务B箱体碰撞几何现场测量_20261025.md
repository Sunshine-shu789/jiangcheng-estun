## 2. 安全边界

1. 进入箱体附近测量前，机械臂必须处于现场负责人确认的安全状态；需要接触箱内区域时，应断电或按现场规程急停锁定。
2. 本测量不允许通过本程序、终端或其他界面点动机械臂或驱动夹爪。
3. 若测量夹爪外廓需要改变夹爪开度，必须先单独获得实体夹爪动作授权；未获授权时只能测量当前断电状态下的可用外廓，并将该项标记为未完成。
4. 照片只能辅助理解结构，不能代替量具读数和测量记录。
5. 未完成几何、坐标、限位、手眼标定和夹爪阈值验证前，Task B 必须保持 `motion.dry_run: true` 和 `gripper.backend: mock`。

## 3. 坐标与单位约定

单位统一使用米和弧度。

箱体局部坐标系定义：

- 原点：箱体内矩形中心。
- `+X`：由西内壁指向东内壁。
- `+Y`：由南内壁指向北内壁。
- `yaw_rad`：基座系 `+X` 逆时针转到箱体系 `+X` 的角度。
- `center_xy_m`：箱体内矩形中心在指定控制柜基座坐标系中的 XY。
- 所有 `vertices_m` 和 `flange_xy_m` 都是对应平面内的二维点。

必须记录控制柜实际使用的基座坐标系名称。不得把房间坐标、相机坐标或估计的机器人坐标直接写进 `controller_base_frame`。如果现场无法把测量基准转换到该基座系，坐标测量仍视为未完成。

俯视示意：

```text
                 北 / box +Y
        northwest              northeast
             +----------------+
             |                |
  西         |       +        |         东
 box -X      |     原点       |      box +X
             |                |
             +----------------+
        southwest              southeast
                 南 / box -Y
```

## 5. 静态测量步骤

### 5.1 建立测量基准

1. 记录日期时间、箱号、测量地点、测量人和复核人。
2. 在箱体外部选择稳定、可复测的基准点，并拍照记录其与机器人基座或控制柜坐标基准的关系。
3. 标出西、东、南、北四条内壁。这里的东南西北由箱体局部 `+X/+Y` 定义，不按房间朝向临时判断。
4. 记录量具编号、量程、分辨率和校准状态。

### 5.2 测量内矩形和中心

1. 在靠近箱口、法兰实际可达的同一水平面测量东西向全宽和南北向全深。
2. 每项至少重复三次，记录每次读数、最大值、最小值和离散量。
3. 用内矩形对角交点或对边中点确定中心，转换为基座系 `[x, y]`。
4. 从基座系 `+X` 到箱体西壁指向东壁的方向测量 `yaw_rad`，确认逆时针为正。
5. `uncertainty_m` 不能只填量具分辨率，还应包含安装基准、转换和重复测量造成的误差。
6. `yaw_uncertainty_rad` 必须来自实际角度复测。安全余量审核必须说明 yaw 误差如何被吸收，不能只满足平移不确定度下限。

### 5.3 测量夹爪法兰外廓

1. 固定并明确法兰坐标系与装配体坐标系的轴向映射。
2. 测量实际装配体在下降姿态时需要投影到法兰 XY 平面的最大外廓，包含手指、硅胶、螺钉、线缆和安装支架。
3. 若夹爪开度可变，应覆盖允许的实际工作开度；未获动作授权时不得驱动夹爪，只能记录为待完成。
4. 将测得外廓转换为法兰系二维点，使用保守外包凸多边形。非凸实体应取外包凸包，不得用内凹轮廓低估碰撞范围。
5. STEP/CAD 可以作为来源之一，但必须与实物版本、装配状态和关键尺寸核对；CAD 包围盒不能直接替代法兰系实测外廓。
6. 点序必须沿边界一致排列，至少 3 个点，且不能退化、自交或非凸。

### 5.4 测量 L 块和凸台

1. 对西北、东北、西南、东南每个下部 L 块分别拍摄并测量。
2. 每个 L 块至少拆成两块严格凸多边形。常用方法是拆成两条矩形长边和短边；更复杂的 L 块应继续拆分。
3. 所有凸多边形顶点统一变换到箱体局部坐标系。
4. 顶点顺序应沿多边形边界一致排列，不能用一条非凸多边形直接表示整个 L 块。
5. 北侧和南侧凸台分别建模，每个至少一个 `edge_boss`；复杂凸台拆成多个凸多边形。
6. 检查是否存在照片中不明显、但会进入下降外廓的台阶、螺栓、限位板或线缆，若有则使用 `other` 分类补充。
7. 任何障碍物顶点超出测得箱体内矩形范围都应重新测量，不得通过扩大箱体尺寸掩盖问题。

示例：一个简单 L 块拆成两个矩形，每个矩形仍是凸多边形；四角合计至少 8 个 `lower_corner`。

```text
箱体西北内角俯视

  +Y
   ^
   |  L 块长边：取矩形四角
   |  +----------+
   |  |          |
   |  |   +------+
   |  |   | L 块短边
   |  |   |
   +--+---+--------> +X
```

### 5.5 选择安全余量

`wall_m` 和 `obstacle_m` 是在实测墙体和障碍边界之外额外收缩的排除量，不是“剩余空间”。两者都必须大于零，且不得小于 `uncertainty_m`。

选择时至少考虑：

- 长度测量和基座系转换误差。
- 箱体 yaw 测量误差。
- 重复安装和箱体位置重复性。
- 夹爪外廓、硅胶压缩和线缆摆动。
- 控制周期、轨迹跟随误差和现场机械间隙。

禁止为了得到可行路线而调小余量。若路线不可行，应报告几何或标定问题，而不是放宽碰撞门禁。

## 6. 证据文件要求

证据目录：

```text

```

正式 YAML 中至少需要以下 8 类证据路径：

1. `overview_photos`：至少 1 个总览文件。
2. `corner_photos.northwest`：至少 1 个西北角文件。
3. `corner_photos.northeast`：至少 1 个东北角文件。
4. `corner_photos.southwest`：至少 1 个西南角文件。
5. `corner_photos.southeast`：至少 1 个东南角文件。
6. `boss_photos.north`：至少 1 个北侧凸台文件。
7. `boss_photos.south`：至少 1 个南侧凸台文件。
8. `gripper_geometry_sources`：至少 1 个夹爪几何文件，可以是实测草图、CAD、STEP 或复核 PDF。

路径可以是绝对路径，也可以是相对 `config/` 目录的路径。为避免歧义，当前正式记录推荐填写绝对路径，例如：

## 7. 填写正式 YAML

只在所有测量和证据真实完成后执行以下操作：

1. 将 `status` 从 `draft` 改为 `reviewed`。
2. 填写 `metadata` 的全部字段，包括带时区的 ISO-8601 测量时间。
3. 填写箱体中心、yaw、内尺寸、两个安全余量和法兰系夹爪外廓。
4. 将 8 个 L 块占位项替换为实际凸多边形；保持名称唯一。
5. 将北、南凸台替换为实际凸多边形；按需增加其他障碍。
6. 填写全部证据路径。
7. 由独立复核人重新核对尺寸、方向、点序和障碍完整性。
8. 仅在实际完成对应工作时，把以下五项设为 `true`：
   - `measurement_complete`
   - `dimensions_rechecked`
   - `all_obstacles_inventoried`
   - `gripper_footprint_reviewed`
   - `safety_approved`
9. `measured_by` 与 `reviewed_by` 必须是不同的两个人，并填写具体复核说明。

等待复核时不要提前把 `status` 或签字项改成完成状态。

## 9. 启用顺序

1. 静态测量记录完整，证据文件存在。
2. 独立复核人完成五项签字，校验器返回 `0`。
3. 生成 `field_measured` 几何块并记录文件摘要。
4. 先只写入 Trial/Preflight，保持 `dry_run: true` 和夹爪 mock。
5. 运行配置加载、规划器和离线路线碰撞测试。
6. 检查所有候选 yaw、下降点和边界余量，确认无触碰。
7. 实体空载运动、夹爪动作和低速实机测试必须分别获得用户明确确认。
8. 几何未全部验证前，不启用任意摆放实体抓取。
