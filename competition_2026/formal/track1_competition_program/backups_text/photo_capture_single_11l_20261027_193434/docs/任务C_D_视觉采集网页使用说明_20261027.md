# 赛道一任务 C/D：桌面 RGB-D 视觉采集网页使用说明

- 文档日期：2026-10-27
- 适用任务：赛道一任务 C/D 的后 30 类物品自采
- 数据用途：不使用官方数据集，采集清单第 11–40 项的实际物品 RGB-D 数据
- 正式程序根目录：`/media/sunshine/新加卷/埃斯顿比赛_2026/赛道一比赛程序`
- 安全边界：本网页只读取 Intel RealSense D405、运行 YOLO 辅助提示并写入数据；**不连接机械臂、不控制夹爪、不发布运动命令**

> 先记住三个原则：第 11–40 类必须人工确认标签；普通采集默认“一帧一个主动选择的目标”；采集期间不要同时运行任务 B/C/D/E 或“抓取识别”。

## 1. 网页升级了什么

1. 类别下拉框已加入清单中的全部 40 个物品名称，并带中文展示名和稳定英文标签。
2. 默认选中第 11 类 `11-Padlock`，方便直接开始后 30 类采集。
3. 后 30 类可以正常采集；当前模型只识别第 1–10 类，因此模型框只作环境辅助，**不能代替人工标签**。
4. 所有照片统一放在新加卷顶层的独立照片根目录：
   ```text
   /media/sunshine/新加卷/赛道一_C_D自采照片
   ```
5. 一次采集会话会同时保存彩色 PNG、16 位深度 PNG、JSON 元数据、预览 JPEG、会话 YAML、逐帧 JSONL 和 SHA256 清单。
6. 新增六种场景标注：台面、小收纳箱内、大收纳箱内、杂乱多物体、靠箱壁、两箱转场。
7. 新增单张采集、连拍、会话管理、最近图片预览和网页内停止服务。
8. 新增独立的高级多物体框选标注区域；普通单目标采集不需要使用。

## 4. 一次标准采集流程

### 4.1 新建或选择会话

推荐一次现场采集使用一个会话，例如：

```text
20261027_session_001
```

操作：

1. 首次打开时，网页会给出会话 ID；
2. 同一批采集复用同一个会话；
3. 如果上一批已经结束，点击“新会话”；
4. 采下第一张后，会话 ID 会锁定，避免误写到别的目录；
5. 需要换会话时点击“新会话”，不要手工混用一个旧目录。

会话 ID 只能使用英文字母、数字、点、下划线和连字符，必须以字母或数字开头，最长 64 个字符。

### 4.2 选择物品类别

在“物品类别”下拉框中选择：

- 第 11–40 类：按物品清单人工选择；
- 第 1–10 类：如果也要补采，同样以人工选择为准；
- 空背景：画面中不摆目标物品时使用。

### 4.3 选择采集场景

六种场景会写入 `scene_type` 和 `box_type`：

| 场景值 | 页面名称 | 记录的 box_type | 用途 |
|---|---|---|---|
| `tabletop` | 台面 | `none` | 基础视角、干净背景 |
| `small_box` | 小收纳箱内 | `small_box` | 小空间、贴边、遮挡 |
| `large_box` | 大收纳箱内 | `large_box` | 远距离、大范围、箱沿遮挡 |
| `clutter` | 杂乱多物体 | `mixed` | 重叠、相互遮挡、多类混放 |
| `near_box_wall` | 靠箱壁 | `mixed` | 透明箱壁、箱沿、角落、反光 |
| `transfer` | 两箱转场 | `mixed` | 大小箱同框或搬运路径 |

`box_type` 是场景元数据，不是物品类别，不会把“小箱/大箱”训练成第 41、42 类。

### 4.4 填写实例、光照和备注

实例 ID 推荐格式：

```text
11-Padlock#01
11-Padlock#02
39-Glove#01
```

同一个物品的多件实物用 `#01`、`#02` 区分。不要使用 `/` 或 `\`。

光照/场地 ID 例如：

```text
site_A
site_B
window_left
overhead_only
```

备注可记录：

```text
透明箱壁反光
物体靠近右后角
部分被其他物品遮挡
手持物块改变俯仰角
```

备注不要超过 1000 个字符。

### 4.5 采一张

调整好物品、视角和光照后，点击：

```text
采一张 RGB-D
```

成功后会显示帧号、类别和本会话累计张数。

单张采集适用于：

- 需要精确控制构图；
- 每个姿态只拍一张；
- 多物体场景需要随后逐帧确认；
- 发现反光、模糊、深度缺失时可立即重拍。

### 4.6 连拍

设置：

- 张数：建议 10–30 张；
- 间隔：建议 350–800 ms；
- 动作：手持物品或相机支架缓慢改变视角/距离/俯仰角。

点击“连拍”。连拍结束前不要快速晃动，否则会产生大量运动模糊和高度重复帧。

建议不要连续保存几十张几乎相同的画面；有效变化比单纯数量更重要。

## 5. 各类物品的采集方法

### 5.1 后 30 类的基础组合

每个物品建议至少覆盖：

1. 台面；
2. 小收纳箱内；
3. 大收纳箱内；
4. 再选择 1–2 个变化场景：杂乱、靠箱壁或两箱转场。

每个场景建议采集 10–20 张有效变化帧。下面是推荐起步量，不是比赛硬性规定：

- 普通规则物体：每个场景 10–15 张；
- 透明、反光、软体、细小物体：每个场景 20–40 张；
- 多姿态、多距离、多光照：优先于大量近似重复图；
- 每个会话完成后立即查看最近缩略图，发现模糊或深度缺失就补拍。

### 5.2 需要重点加量的物品

透明或反光：碗、酒杯、塑料杯、可乐瓶、透明胶带、眼镜/玻璃类物品。

软体或易变形：T 恤、手套、毛绒玩具、纸巾。

细小物体：钥匙、钉子、勺子、螺丝刀、骰子、转接头。

大件或长条物体：书、活动扳手、大号笔筒、纸巾。

### 5.3 变化维度

每个物品尽量改变：

- 位置：中间、边缘、角落；
- 姿态：正放、侧放、倒放、斜放；
- 距离：近、中、远；
- 视角：俯视、斜视、低角度；
- 光照：正面光、侧光、逆光、阴影；
- 遮挡：单独放置、部分遮挡、多物体重叠；
- 箱体关系：离箱壁远、贴箱壁、跨箱沿、两箱同框。

## 6. 照片保存位置和目录结构

统一照片根目录（直接位于新加卷中）：

```text
/media/sunshine/新加卷/赛道一_C_D自采照片
```

每个会话一个子目录：

```text
photos/
  20261027_session_001/
    rgb/
      000001_11-Padlock.png
      000002_11-Padlock.png
    depth/
      000001_11-Padlock.depth.png
      000002_11-Padlock.depth.png
    meta/
      000001_11-Padlock.json
      000002_11-Padlock.json
    overlays/
      000001_11-Padlock.jpg
      000002_11-Padlock.jpg
    frames.jsonl
    session.yaml
    SHA256SUMS
```

保存规格：

- `rgb/`：彩色 PNG，BGR8；
- `depth/`：原始 16 位 PNG，uint16；
- `meta/`：逐帧 JSON，含类别、实例、场景、箱体、光照、内参、深度尺度、旋转、模型辅助结果；
- `overlays/`：带类别文字的预览 JPEG，只用于人工检查；
- `frames.jsonl`：逐帧元数据索引；
- `session.yaml`：会话统计和相机信息；
- `SHA256SUMS`：文件完整性校验。

彩色图和深度图来自同一对齐帧。原始 PNG 和深度 PNG 不要用图片查看器另存或压缩。

## 8. 为什么任务 C/D 有大、小箱子

这是任务设置本身决定的，不是网页额外增加了两个物品类别：

- 任务 C 是在大收纳箱和小收纳箱之间进行非顺序抓取和放置；
- 大箱空间大、物体多，相机到目标距离变化大，还要处理箱沿和远处遮挡；
- 小箱空间紧、遮挡强，物体容易靠边、靠角，抓取净空和碰撞约束更明显。

因此同一物品最好在大箱、小箱和台面都采到，不要只拍干净台面。网页把大/小箱记录为 `box_type` 场景元数据，便于后续按箱体场景评估，而不是把它们混进 40 类标签。

## 9. 多物体同帧和高级框选标注

普通模式默认“一帧一个主动选择的目标类别”，适合分类和单目标检测数据。

如果一帧里同时有多个物品：

1. 普通采图仍选择一个主要目标标签；
2. 若要保留多物体 bbox 标注，展开网页底部“高级：多物体场景标注”；
3. 点击“冻结并分割”；
4. 系统给出深度候选；
5. 对每个候选选择类别，或使用“手动框选”补框；
6. 不需要的候选选“忽略此候选”；
7. 点击“保存标注”。

高级标注保存到独立目录：

```text
/media/sunshine/新加卷/埃斯顿比赛_2026/赛道一比赛程序/datasets/track1_selfcollected_v1/annotations
```

不要把普通 `photos/` 采集误认为已经完成了所有多物体检测框标注。多物体训练前仍需要检查 annotations 和派生标签。

## 12. 常见问题

### 网页打不开

查看：

```text
/media/sunshine/新加卷/埃斯顿比赛_2026/赛道一比赛程序/logs/track1_capture_web/preview.log
```

并确认端口 9110 没有被其他程序占用。

### 提示 D405 被占用

- 被“视觉识别”或“抓取识别”占用：双击“赛道一 照片采集”，在弹出的确认框中选择停止旧识别并启动采集；
- 被任务 B/C/D/E、`realsense-viewer` 或其他程序占用：本入口不会自动停止它们；先按对应正式流程停止，再重新双击；
- 确认框点击“取消”或停止失败：照片采集不会启动，旧程序保持或由原停止程序处理，不会强杀未知进程。

### 采图按钮一直灰

通常是相机、深度流、模型或内参尚未就绪。先看右上角状态和日志，不要反复点击。

### 深度图全是 0 或大面积空洞

检查 D405 深度流、物体距离、透明/反光表面和线缆。透明物体会出现深度缺失，需要改变角度和背景，并记录备注。

### 采错了类别

不要改已有 JSON 或文件名。停止当前会话，重新建立新会话并重拍；已有原始数据保留。

### 同一会话相机序列号不同

网页会拒绝写入。说明更换了 D405 或相机重新枚举，必须新建会话。
