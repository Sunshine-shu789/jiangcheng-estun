## 本次修正

- 任意摆放抓取改为严格竖直向下：夹爪工具 Z 轴必须为 `(0, 0, -1)`。
- `pitch_offsets_deg` 只允许 `[0.0]`，禁止通过正负手腕倾角回退。
- 保留 5 个绕竖直工具轴的朝向候选：
  `0, +45, -45, +90, -90 deg`。这些候选只调整 J6/腕部朝向，不倾斜夹爪。
- 配置加载、候选生成、离线验收矩阵、完整路线预检和每个运动/夹爪命令发出前均检查竖直条件。
- 任意摆放模式必须显式配置 `motion.grasp_rpy`，当前四套配置均为
  `[3.14159265, 0.0, 0.0]`。
- 最终抓取深度没有通过 `approach_height_m` 修正。接近高度只控制预抓取点，不能改变最终夹爪最低点。
- 工具几何继续使用法兰到夹爪最低点的 `[0, 0, 0.165] m`。该方向与竖直向下朝向结合后得到基座系偏移 `[0, 0, -0.165] m`。
- Mock 的接近高度调整为 `0.08 m`，仅用于避免离线场景法兰工作空间越界；Trial、Preflight、Live 保持 `0.05 m`。
- 增加低矮物体支撑面兜底：当物体与箱底深度差小于 `20 mm`、双峰深度分层不成立时，使用目标颜色掩码排除物体，在检测框外局部环带用同一套 RANSAC 拟合支撑面。RMS、内点率、法向和最少点数门限均未放宽。
- 低矮兜底只补充支撑面采样方式，不绕过 `support_plane_required`；没有真实平面时仍会拒绝抓取。


## MS42DC 到位状态修复

2026-10-25 21:06 的日志显示，闭合命令发出后约 `8 ms` 返回的上一条到位状态为
`angle=20.8 deg`，这不能证明夹爪已经完成闭合。修复后的逻辑规定：

- 从张开切换到闭合、或从闭合切换到张开时，必须至少观察到一次
  `arrived=false` 的新状态；
- 只有随后再次观察到 `arrived=true`，夹爪动作才算完成；
- 请求已经处于同一状态时，允许因硬限位而原地不动；
- 超时仍按原配置报错，不会在夹爪尚未完成动作时让机械臂继续抬升。

该修复只改变夹爪反馈判定，不改变夹爪行程、方向、速度或抓取高度。相关测试
`38/38` 通过，全量离线测试 `315/315` 通过。修复后尚未发送新的实体夹爪命令。
