## 严格数值门禁

IK 航点验收与控制器到位反馈容差已拆开：

```text
ik_position_tolerance_m        = 0.0002 m      # 0.2 mm
ik_orientation_tolerance_rad   = 0.0002 rad
position_tolerance_m           = 0.003 m       # 控制器/反馈完成容差，不用于 IK 航点验收
cartesian_joint_step_deg       = 0.5 deg
joint_limit_margin_deg         = 2.0 deg
cartesian_min_jacobian_singular_value = 0.01
```

旧逻辑可能在最终残差尚未重新计算或候选超出本步关节限制时返回结果。现在只有最终 FK 重新计算后同时满足严格位置、姿态容差，并继续通过调用方校验的候选才可返回。

## 解析 Jacobian 与 FK

- 新增 `_controller_frames()`，在一次 modified-DH 计算中同时返回工具位姿、各关节原点和轴线。
- `controller_jacobian()` 改为解析几何 Jacobian，不再做逐关节数值扰动。
- FK 与 Jacobian 共用同一 DH 实现，减少两套公式漂移风险。
- 解析 Jacobian 与中心差分的最大绝对误差实测为 `8.9e-11`。

## 自适应阻尼与最终验收

`solve_pose_ik()` 现在使用：

- 增广最小二乘，不显式构造 `J.T @ J`；
- SVD 稳定的 `np.linalg.lstsq`；
- 自适应 Levenberg-Marquardt 阻尼；
- 关节步长裁剪和最小二乘线搜索；
- 迭代结束后重新计算 FK、位置残差、姿态残差、Jacobian 奇异值和限位状态；
- 失败信息包含位置残差、姿态残差、迭代数、阻尼和是否碰限位。

单个局部解在奇异 home 位姿附近可能停留在较高残差分支，因此生产链不能依赖固定阻尼单次求解。

## 确定性多起点

`solve_pose_ik_multistart()` 的行为固定为：

1. 始终先尝试当前实测关节姿态；
2. 主种子按固定阻尼序列尝试；
3. 主种子没有安全候选时，按固定顺序尝试单轴扰动种子：`J4, J6, J5, J1, J3, J2`；
4. 普通目标种子偏移 `2 deg`；连续路径使用 `min(0.25 deg, 0.5 * step_limit)`；
5. 每个候选都对原始姿态重新检查关节步长，不允许“换分支后才满足”的候选通过；
6. 候选按归一化位姿残差、最大关节运动、Jacobian 奇异值、种子次序统一排序；
7. 所有过程无随机数，同一输入得到相同关节解和诊断。

近奇异 home 点纯平移测试中，固定阻尼会留下约 `0.51 mrad` 姿态残差；确定性多阻尼路径可收敛到 `0.149 mrad` 以内，随后继续接受调用方的奇异裕度检查。

## 步长、限位和奇异值 fail-closed

- 设置 `accept_delta_rad` 后，超步长候选默认直接拒绝。
- 仅笛卡尔路径细分器可显式设置 `allow_unbounded_fallback=True`，取得一个“位姿已收敛但超出本步限制”的粗端点，用于继续细分路径。
- 即使启用粗端点回退，运动层仍会再次计算该端点的 FK、关节限位、位姿误差和奇异值；后续轨迹每个细分航点仍必须满足 `0.5 deg` 限制。
- 近奇异候选即使位置/姿态收敛，也会被调用方 Jacobian 门限拒绝并报告 fail-closed。
- 目标旋转必须有限、正交且 `det=+1`；反射矩阵、非正交矩阵、NaN 和错误形状均拒绝。
- 阻尼、迭代数、容差、限位裕度、种子偏移和最小奇异值均有有限值和范围检查。

专项测试中的奇异 home 候选最小奇异值约 `5.2e-5`，低于生产门限 `0.01`，已被拒绝，没有通过放宽门限掩盖问题。

## 压力测试口径

压力测试不是只重放固定样例，而是：

1. 在典型工作姿态附近按固定随机种子生成姿态，六个关节各偏转最多 `20 deg`；
2. 先过滤加权 Jacobian 最小奇异值低于 `0.011` 的基准姿态；
3. 从该姿态生成最多 `0.10 deg` 的测量种子扰动；
4. 再由可达目标关节生成 FK 位姿，目标相对测量种子每轴最多变化 `0.38 deg`；
5. 使用生产多起点和严格 `0.5 deg` 步长门禁求解。

结果：

```text
success       = 240 / 240
mean latency  =  3.539 ms
p95 latency   = 11.613 ms
max latency   = 13.095 ms
restart seeds = 0
```

这说明本轮压力集内所有目标都由主种子收敛，未靠偏移种子跨分支通过。偏移种子的独立回退测试由专项测试覆盖。

## 箱体位姿与 IK 的边界

逆解算本身**不能**从固定箱体尺寸唯一推出箱体中心 `[x,y]` 和 `yaw`。可靠链路仍必须是：

```text
手眼标定
  -> RGB-D 获取箱体四角
  -> 捕获时关节角经 FK 转法兰/基座
  -> 四角转基座系
  -> 拟合矩形得到中心、yaw、尺寸
  -> IK 验证抓取点、凸台和 L 块附近的路径可达性、连续性和奇异裕度
```

已知箱体内尺寸、凸台和法兰最大外廓属于碰撞几何，不属于 IK 的未知量。不能把五个抓取点或 IK 结果当作箱体几何真值。
