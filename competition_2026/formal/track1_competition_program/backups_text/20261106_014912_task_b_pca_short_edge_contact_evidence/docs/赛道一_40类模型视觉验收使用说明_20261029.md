日期：2026-10-29

## 1. 本轮目标

- 只读取 D405 彩色画面并运行 YOLO。
- 不连接 ROS。

1. 页面顶部显示“识别正常运行”。

## 5. 验收顺序

### 第一步：前 10 类逐类确认

必须逐个摆放并确认类别编号、英文名和画面中物品一致：

| ID | 物品 |
|---:|---|
| 00 | 1-Cheez-it |
| 01 | 2-Starkist_Tuna |
| 02 | 3-Scissors |
| 03 | 4-Frenchs_Mustard |
| 04 | 5-Tomato_Soup |
| 05 | 6-Foam_Brick |
| 06 | 7-Clamp |
| 07 | 8-Plastic_Banana |
| 08 | 9-Mug |
| 09 | 10-meat_can |

前 10 类全部通过后，才继续后 28 类。

### 第二步：后 28 个已采集物品逐类确认

类别范围为 ID 10–39，但跳过：

- ID 16：17-Eggs_Plush
- ID 25：26-Plastic_Strawberry

重点检查小目标：

- ID 17：18-Dice
- ID 21：22-E27_Adapter
- ID 22：23-GU24_Adapter
- ID 23：24-Spoon
- ID 32：33-Key
- ID 33：34-Nail

默认置信度为 `0.15`。小目标只有在确实难以出框时，才临时降到 `0.08–0.12`；通过后应恢复 `0.15`，避免低分误框被当成通过。

### 第三步：多物品同画面抽测

建议至少测试以下场景：

- 前 10 类中的 3–5 件物品同画面。
- 后 28 类中的 3–5 件物品同画面。
- 大小差异明显的一组物品。
- 相互贴近或部分遮挡的一组物品。

检查：

- 是否漏掉小物品。
- 是否把同一物品画成多个框。
- 是否出现跨类别重复框。
- 类别是否在相邻帧之间明显跳变。
- ID 和英文名是否与训练类别表一致。

## 6. 通过标准

某一类同时满足以下条件才记为通过：

- 能稳定识别出目标。
- 类别 ID 正确。
- 英文类别名正确。
- 没有明显重复框。
- 没有与具体物品重叠的错误类别框。
- 单物品和多物品同画面抽测均正常。

前 10 类必须全部通过，不能以“后 10 类训练好”为理由忽略前 10 类现场识别。

## 7. 留证方法

发现错类、漏框、重复框或类别跳变时：

1. 保持当前画面不要动。
2. 点击“保存验收截图”。
3. 页面会显示截图绝对路径。
4. 在日志目录中可找到同名 `.jpg` 和 `.json`。

## 9. 常见问题

### 页面一直显示正在初始化

检查相机日志：

```bash
tail -n 80 /media/sunshine/新加卷/埃斯顿比赛_2026/赛道一比赛程序/logs/track1_acceptance_web/server.log
```

重点确认 D405 是否被其他识别程序占用。验收程序和旧“抓取识别”不能同时占用同一台相机。

### 页面提示模型 SHA 不一致

说明加载的不是已验证的最终权重。停止服务并检查配置：

```text
/media/sunshine/新加卷/埃斯顿比赛_2026/赛道一比赛程序/config/track1_acceptance_40class.yaml
```

### 小目标没有框

先将物体放到画面中央、保持约 25–45 cm 距离、避免强烈反光，再把阈值临时降到 `0.08–0.12`。通过后恢复 `0.15`。

### 端口 9120 被占用

检查旧验收进程：

```bash
/media/sunshine/新加卷/埃斯顿比赛_2026/赛道一比赛程序/bin/stop_track1_40class_acceptance
```

然后重新启动。

## 10. 验收后的下一步

只有视觉验收完成后，才新增 C/D 的 40 类干运行配置。新增配置必须保持：

```yaml
motion:
  dry_run: true
gripper:
  backend: mock
```

验收阶段不建议直接启用实体机械臂运动。现场坐标、限位、手眼标定和夹爪阈值未确认前，继续干运行。
