## 最新状态：箱边与角块碰撞防护

截至 2026-10-25，任意摆放抓取新增了基于箱内 XY 平面的保守碰撞门：

- 规划器在生成每个 yaw 候选时，先按完整候选旋转把法兰 XY 外廓投影到基座系，再检查箱壁内缩区、四角 L 块和上下凸台；碰撞候选只记录失败并继续尝试下一个候选。
- Pipeline 在完整路线预检和任何运动/夹爪命令之前再次执行同一检查，防止候选计划被替换或损坏后绕过规划器门禁。
- 完整几何缺失、未标记验证、来源未配置、NaN、退化/凹多边形或非正交旋转均 fail closed。
- Mock 合成几何仅允许用于
  `vision=mock + motion=mock + dry_run=true + gripper=mock` 的完整离线链。

**重要：代码完成不等于箱体几何已验证。** 当前还没有完成比赛现场箱内壁、
四角 L 块、上下凸台和真实法兰外廓的静态测量。Trial、Preflight、Live
三套实机链均配置为：

```yaml
box_clearance:
  required: true
  geometry_validated: false
  geometry_source: unconfigured
```

因此这三套配置会在 `load_config()` 阶段直接失败，不会进入运动规划或发出
任何实体机械臂、夹爪命令。这是预期安全行为，不应通过把
`geometry_validated` 手工改成 `true` 来绕过。

当前 Mock 配置中的箱体中心、`1.40 x 1.40 m` 内尺寸、墙间隙 `0.08 m`、
障碍间隙 `0.02 m`、四角 L 形挡块、南北凸台以及居中的
`0.118 x 0.063 m` 法兰外廓都是**合成测试值**，只用于覆盖算法路径，不是
现场尺寸，不能复制到实机配置。四角 L 形挡块在测试中拆成多个严格凸多边形，
因为碰撞校验器会拒绝凹多边形。

实机启用前至少需要完成：

1. 以机器人基座系测量箱体内壁中心和完整内尺寸，并记录箱体 `yaw`。
2. 分别静态测量四个角的 L 形挡块；每个可见 L 形必须拆成多个凸多边形。
3. 测量箱体上沿/下沿凸台，以及可能进入法兰 XY 投影范围的全部结构。
4. 从实际末端装配和夹爪 CAD/实物测量法兰系外廓，不能只使用装配总包围盒或照片估算。
5. 将测得的完整几何写入对应实机配置，复核多边形不自交且每个障碍位于箱内，
   再由现场负责人显式确认 `geometry_source: field_measured` 和
   `geometry_validated: true`。

本轮只执行了代码、pytest、Mock 和离线诊断，没有执行实体机械臂或实体夹爪运动。

## 本次修正

- 任意摆放抓取改为严格竖直向下：夹爪工具 Z 轴必须为 `(0, 0, -1)`。
- `pitch_offsets_deg` 只允许 `[0.0]`，禁止通过正负手腕倾角回退。
- 保留 5 个绕竖直工具轴的朝向候选：
  `0, +45, -45, +90, -90 deg`。这些候选只调整 J6/腕部朝向，不倾斜夹爪。
- 配置加载、候选生成、离线验收矩阵、完整路线预检和每个运动/夹爪命令发出前均检查竖直条件。
- 任意摆放模式必须显式配置 `motion.grasp_rpy`，当前四套配置均为
  `[3.14159265, 0.0, 0.0]`。
- 最终抓取深度没有通过 `approach_height_m` 修正。接近高度只控制预抓取点，不能改变最终夹爪最低点。
- 工具几何继续使用法兰到夹爪最低点的 `[0, 0, 0.165] m`。该方向与竖直向下朝向结合后得到基座系偏移 `[0, 0, -0.165] m`。
- Mock 的接近高度调整为 `0.08 m`，仅用于避免离线场景法兰工作空间越界；Trial、Preflight、Live 保持 `0.05 m`。
- 增加低矮物体支撑面兜底：当物体与箱底深度差小于 `20 mm`、双峰深度分层不成立时，使用目标颜色掩码排除物体，在检测框外局部环带用同一套 RANSAC 拟合支撑面。RMS、内点率、法向和最少点数门限均未放宽。
- 低矮兜底只补充支撑面采样方式，不绕过 `support_plane_required`；没有真实平面时仍会拒绝抓取。

## 高度定义

实机配置的最终夹爪最低点目标为：

```text

```

2026-10-25 实机单点测试后，按现场观察将实机链（Trial、Preflight、Live）
的 `jaw_tip_clearance_m` 从 `0.015 m` 统一提高到 `0.025 m`，即最终抓取高度
整体增加 `10 mm`。它表示夹爪最低点保持在拟合支撑面上方 25 mm，不是法兰高度，
也不是接近高度。离线 Mock 继续使用已知的 `0.002 m` 测试值，避免改变既有离线
矩阵基线。

## MS42DC 到位状态修复

2026-10-25 21:06 的日志显示，闭合命令发出后约 `8 ms` 返回的上一条到位状态为
`angle=20.8 deg`，这不能证明夹爪已经完成闭合。修复后的逻辑规定：

- 从张开切换到闭合、或从闭合切换到张开时，必须至少观察到一次
  `arrived=false` 的新状态；
- 只有随后再次观察到 `arrived=true`，夹爪动作才算完成；
- 请求已经处于同一状态时，允许因硬限位而原地不动；
- 超时仍按原配置报错，不会在夹爪尚未完成动作时让机械臂继续抬升。

该修复只改变夹爪反馈判定，不改变夹爪行程、方向、速度或抓取高度。相关测试
`38/38` 通过，全量离线测试 `315/315` 通过。修复后尚未发送新的实体夹爪命令。
